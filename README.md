# 상담 대시보드 안드로이드 앱

`https://m.sangdam.today/S10079/dashboard` 페이지를 휴대폰 앱처럼 열어 주는 안드로이드 앱입니다.
(앱 안에 웹 화면을 띄우는 WebView 방식이라, 웹사이트가 바뀌면 앱에도 바로 반영됩니다.)

## 설치 방법 (안드로이드)
1. 휴대폰에서 이 저장소의 **Releases → "상담 대시보드 앱 (최신)"** 으로 이동
2. `sangdam-app.apk` 를 내려받아 실행
3. "출처를 알 수 없는 앱 설치" 허용 안내가 나오면 허용 후 설치

코드를 고쳐서 push 하면 GitHub Actions 가 자동으로 새 APK 를 만들어 같은 Releases 에 올립니다.
같은 키로 서명하므로 새 APK 를 기존 앱 위에 그대로 덮어 설치할 수 있습니다(로그인 유지).

## 기능
- 로그인 상태(쿠키) 유지
- 뒤로 버튼 → 이전 페이지, 첫 화면에서 두 번 누르면 종료
- 파일 첨부(업로드), 파일 다운로드(알림창/다운로드 폴더)
- 전화·문자·메일·카카오톡 등 링크는 해당 앱으로 연결
- 인터넷 연결 오류 시 "다시 시도" 화면

## 바꾸고 싶을 때
| 바꿀 것 | 파일 |
|---|---|
| 시작 주소, 앱 이름 | `app/src/main/res/values/strings.xml` |
| 아이콘 색 | `app/src/main/res/values/colors.xml` |
| 아이콘 모양 | `app/src/main/res/drawable/ic_launcher_foreground.xml` |

## 참고
- iPhone 은 이 APK 를 쓸 수 없습니다. Safari 에서 페이지를 연 뒤 **공유 → 홈 화면에 추가** 하면 앱처럼 아이콘이 생깁니다.
  정식 iOS 앱은 Mac + Apple 개발자 계정(연 $99)이 필요합니다.
- Play 스토어 배포용이 아닌 개인/내부용 설치 파일입니다. 스토어에 올리려면 별도 서명 키를 만들어야 합니다.
